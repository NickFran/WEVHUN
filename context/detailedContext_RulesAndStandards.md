# Rules and Standards
The rules and standards context ensures 2 things,
* 1: that users know how to use this software ethically 
* 2: that developers understand how code should be written to adhere to the software development and coding best practices and standards WEVHUN adheres to.


### User Rules and Standards
* If WEVHUN is directed towards a real web system, confirmation has to be established that testing is about to take place to limit confusion surrounding testing.
* All WEVHUN use needs to be done ethically without intending to cause real damage, so long as the developer (and AI) promise this, then no harm will be done and WEVHUN is free to be built and used for everything without fear of real worlsd damage.

### Developer Rules and Standards
* If the completion of a task involves creating a small function, operation, or process. Dont just implement it right away, almost make sure to double check if it has alredy been implemented elsewhere in the codebase and project, if so, then reuse what has already been created rather than blindly create. (this will cut down on duplicate code).
